A QUICK FIELD GUIDE

From edges to experiments.

1. Make a signal

Add an input and enter transition times, or click its waveform track. Click an existing edge to remove it. Drag an input or clock edge to move it. Clock edge edits affect only that transition; change clock settings in Edit to regenerate a regular clock. Choose Draw if a cursor or marker tool is active. Snap follows the Grid setting; switch it off for fine adjustments. Hold Alt to pan, or scroll horizontally.

2. Shift it in time

Select Shift copy, choose a source, then enter 45 ps. A negative shift advances the signal. The copy stays linked to its source.

3. Make logic

Use the gate builder or enter an expression. Names use letters, numbers and underscores. Examples:

Y = A ^ A_shift
OUT = (A AND B) OR !EN
M = mux(SEL, D0, D1)
D = delay(A, -45ps)

Precedence: NOT → AND/NAND → XOR/XNOR → OR/NOR. Gate delays apply to each operation; explicit delay() adds a transport shift. MUX selects D0 when SEL=0 and D1 when SEL=1.

Pin points & add markers

Choose Pin point and click a waveform, or press and hold a track for half a second. Points follow the waveform at their pinned time. Use Vertical for a time reference across all tracks, or Horizontal for a level reference. Drag a marker to reposition it. Rename, lock, or remove each marker in the list below the diagram. Markers are saved with projects and included in diagram exports. Markers outside the current time window stay saved.

Drag to change duration

The Time window slider shortens or extends the simulation duration and updates the waveforms as you drag. Use the reset icon to center its range on the current duration. The toolbar’s + and − buttons control horizontal magnification separately.

Measure & export

Enable Cursors and click twice, or drag the cursor handles. The inspector shows completed pulse widths and rising-to-rising period. Duty cycle covers the full window. Use Export for diagrams or data. PDF uses your browser’s Print → Save as PDF.

Flip-flops

Use Add flip-flop for D, T, JK, or SR storage. Choose a clock, rising/falling edge, inputs, initial Q, and clock-to-Q delay. Enable defaults to 1; synchronous active-HIGH reset defaults to 0 and takes priority over enable. Q becomes a signal you can use in any later expression. Create Q̅ with !Q and zero NOT delay for an ideal complement.

Data and controls are sampled immediately before the active clock edge. Simultaneous data changes use the old value, so cascaded flip-flops capture the preceding stage’s old Q. This deterministic ideal model does not simulate setup/hold violations or metastability. SR with S=R=1 at a sampled edge reports an error.

Expressions also support dff(D,CLK), tff(T,CLK), jkff(J,K,CLK), and srff(S,R,CLK). These shorthand functions use rising edges, initial Q=0, and zero clock-to-Q delay; wrap in delay() for a fixed shift. Use the dedicated form for falling edges, enable, reset, and initial state. External feedback loops are not supported; use T or JK for toggling.

Simulation notes

Signals hold their initial level before their first transition. Simultaneous events are evaluated together. Transport preserves every transition. Inertial gates suppress ideal pulses shorter than the rejection time (gate delay by default). Input and shifted copies remain transport signals. This tool supports combinational logic and ideal edge-triggered flip-flops with feed-forward dependencies; it does not model analog rise/fall, unknown states, metastability, or external feedback loops.

Clock phase and start offset its first cycle; cycle limit 0 fills the window. Clock syntax is configured in the Clock form. Very large experiments are limited to 30,000 clock cycles per signal.
